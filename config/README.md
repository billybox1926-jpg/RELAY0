# Config

Configuration notes and local environment examples for RELAY-0.

RELAY-0 is a Roku channel, so there is no long-running server runtime and no `.env` for the game itself. This folder is for developer-side notes and any future tooling config.

## Current contents

- `.env.example` — placeholder for developer tooling that may use environment values. Not used by the Roku channel at runtime.

## Future use

If you add packaging, lint, or CI helpers that need configuration, keep examples here and keep real secrets out of the repo.
