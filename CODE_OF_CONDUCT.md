# Code of Conduct

RELAY-0 is a small Roku game project. We want the repo and community to stay welcoming, calm, and useful.

## Our standards

We are committed to a harassment-free experience for everyone.

Examples of expected behavior:

- Respectful, constructive communication
- Graceful acceptance of feedback
- Prioritizing community well-being
- Clear, honest issue reports and PR descriptions

## Unacceptable behavior

Unacceptable behavior includes:

- Harassment, insults, or personal attacks
- Trolling or deliberate disruption
- Publishing private information without permission
- Using the repo or issues to send unrelated spam or abuse

## Enforcement

Project maintainers may remove, edit, or reject comments, commits, code, issues, and other contributions that violate this Code of Conduct.

Decisions are made with the goal of keeping the project healthy and usable, not of building a public drama track.

## Reporting

Report concerns privately through the channels defined in the repository settings and `SECURITY.md`.

If you report a violation, include enough detail that the maintainers can understand what happened and where.

## Scope

This Code of Conduct applies to the RELAY-0 repository, related issue threads, and other project spaces where maintainers can reasonably act on behavior.
